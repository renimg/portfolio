Exercise 1

This was my first attempt at using p5.js, I had a tiny bit of code knowledge from the small bit of work I do on a game in my free time
But I had never drawn an image using code before.
There are a few small hotkeys you can use to toggle some elements.
You can toggle the random background with "B", and toggle debug text with "T".
You can also click the nose to make his tongue stick out.

I had a lot of fun making this, and I want to do more like this in the future.
Definitely some things I wish I figured out, like having the eyes trackable with the mouse, but I am happy with how it turned out for my first time.
