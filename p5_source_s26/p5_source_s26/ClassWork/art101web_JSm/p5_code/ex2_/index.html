Once I got my footing in code, I added some extra elements to make it funnier and to pratice using delta timme and loops.
I used a delta time offset to reset the position of my elements to have them look like they're looping around the screen, and a rotate function to spin my image.
The font I used didn't have character kerning, so I had to make it vertical instead of horizontal. It let me mess with the line spacing to have it shrink as it gets closer.
You can toggle the background with "B", and toggle debug text with "T".
