Sucker Punched

This is one of 3 parts of a texture set I created for a Team Fortress 2 Workshop submission called "Sucker Punched".
The peppermint texture was designed to be seamless, meaning no matter how many times it tiles, it will always appear as one continuous texture.
Each individual peppermint was created by me. It has 4 different variants, each with 7 colors to choose from.
